# Project Rules & Customizations - Expense Tracker App

## Documentation Synchronization (Compulsory Rule)
1. **Continuous Documentation Sync**: Always maintain exact tracking of development progress. 
2. **Codebase-Document Alignment**: Whenever new code, features, architecture components, database entities, or parsers are implemented or modified, all relevant specification documents (`Expense_Tracker_SRS_v5.md`, `Expense_Tracker_Implementation_Document_v4.md`, `Expense_Tracker_Idea_Document_v4.md`, `Expense_Tracker_Product_Roadmap.md`, `walkthrough.md`, and `.docx` counterparts) MUST be updated immediately to reflect the latest state of the codebase.
3. **Commit Integrity**: Ensure documentation updates are tracked alongside code changes in Git commits.
