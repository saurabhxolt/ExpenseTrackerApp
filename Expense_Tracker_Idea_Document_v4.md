# Expense Tracker App - Product Vision & Idea Document
Version: 5.0 | Product Vision & Strategic Positioning

# Vision Statement
Build an offline-first, privacy-focused personal expense tracker that automatically captures bank and UPI transactions across multiple channels (SMS + App Notifications) using an intelligent multi-stage NLP parser (with robust rejection of news digests and bill due reminders, enforcing explicit execution action verbs), applies Credit Card accounting intelligence (classifying swipes/online/RuPay UPI as DEBIT expenses and bill payments/receipts as TRANSFER debt repayments to eliminate double-counting and income inflation, with universal VPA regex handle parsing for unknown payment aggregators), applies window-based and timeless anti-duplication with automatic DB cleanup, provides an **Offline Peer-to-Peer Split Expenses (Splitwise alternative)** ledger with real-time "Who Owes Whom" calculation and 1-click WhatsApp Settlement Summary export, integrates top app header Settings navigation alongside 5 main bottom tabs (Dashboard, History, Split Bills, Budgets, Analytics), categorizes expenses locally across a unified 18-category taxonomy, provides interactive Canvas visual charts with date/period filter controls, allows manual category re-assignment and raw SMS viewing, pushes bill due date reminders, features a home screen widget, includes an in-house privacy-first promotion engine (static JSON, zero third-party ads), and keeps 100% of user data strictly on the user's device.
