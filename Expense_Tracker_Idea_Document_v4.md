# Expense Tracker App - Product Vision & Idea Document
Version: 4.0 | Product Vision & Strategic Positioning

# Vision Statement
Build an offline-first, privacy-focused personal expense tracker that automatically captures bank and UPI transactions across multiple channels (SMS + App Notifications) using a generic multi-stage NLP parser with window-based anti-duplication, categorizes expenses locally, provides interactive Canvas visual charts, allows manual category re-assignment and raw SMS viewing, pushes bill due date reminders, features a home screen widget, includes an in-house privacy-first promotion engine (static JSON, zero third-party ads), and keeps 100% of user data strictly on the user's device.
