# Expense Tracker App - Product Vision & Idea Document
Version: 5.6 | Product Vision & Strategic Positioning

# Vision Statement
Build an offline-first, privacy-focused personal expense tracker that automatically prompts system runtime permissions (`READ_SMS`, `RECEIVE_SMS`, `POST_NOTIFICATIONS`) immediately on first launch, features **Peek Privacy Mode & Shake-to-Hide** with an accelerometer sensor listener and top bar eye toggle to mask sensitive balances (`₹•••••`) on the fly, features a **Safe-to-Spend Today Radar** on the Dashboard computing real-time daily discretionary spending limits paced against remaining calendar days in the month while factoring in reserved committed bills, includes **Automated Local Rolling Backups** with weekly encrypted database snapshots kept in local sandbox with 5-version rolling retention and in-app restore, integrates a **Stealth Inflation & Subscription Price Creep Detector** flagging silent price increases across repeat merchants and subscriptions, features **Visual Sinking Funds & Savings Goals (Interactive "Jars")** with custom targets, emojis, colors, deadline timeframes, dynamic monthly savings pace calculators, and 1-tap deposit/withdraw dialogs, integrates an **Indian Tax Season Deductions Organizer (80C / 80D / HRA)** automatically tracking tax-exempt debits against statutory ceilings with 1-tap CA/ITR export, provides an **Itemized Restaurant & Group Bill Splitter** with proportional tax and tip distribution and WhatsApp summary generation, automatically captures bank and UPI transactions across multiple channels (SMS + App Notifications) using an intelligent multi-stage NLP parser (equipped with dedicated SMS transaction parser agent skill `.agents/skills/sms_transaction_parser/SKILL.md`, dedicated category memory agent skill `.agents/skills/category_assignment_agent/SKILL.md`, `CategoryClassifier` for repeat merchant preference memory learning, `SubscriptionMatcher` for automatic SMS/notification transaction-to-subscription auto-linking and cycle advancement, `SubscriptionDetector` Smart Subscription Radar for 1-tap onboarding of recurring debits, robust rejection of festive loan offers, EMI conversion marketing prompts, news digests, and bill due reminders, strict word boundary safety preventing "to credit" collisions, and enforcing explicit execution action verbs), applies Credit Card accounting intelligence (classifying swipes/online/RuPay UPI as DEBIT expenses and bill payments/receipts as TRANSFER debt repayments to eliminate double-counting and income inflation, with universal VPA regex handle parsing for unknown payment aggregators), applies window-based and timeless anti-duplication with automatic DB cleanup, provides an **Offline Peer-to-Peer Split Expenses (Splitwise alternative)** ledger with real-time "Who Owes Whom" calculation and 1-click WhatsApp Settlement Summary export, integrates top app header Settings navigation alongside 5 main bottom tabs (Dashboard, History, Split Bills, Budgets, Analytics), features dynamic category budget management with safe upserting, resilient full-schema JSON disaster recovery backup/restore, a **Unified Editable Category Manager** rendering system and custom categories in a single editable list with true SQL `UPDATE` in-place editing, historical transaction category synchronization, smart name-based category emojis (`CategoryEmojiProvider.kt`), and system-managed distinct color auto-assignment (`CategoryColorProvider.kt`), features a **Type-Aware Donut Breakdown Chart** (`AnalyticsScreen.kt`) computing percentages relative to the selected transaction type (Expenses, Income, Investments, Transfers, All), features a **Dashboard Monthly Mandates Commitment Card** displaying total committed recurring outflows vs paid so far, provides interactive Canvas visual charts with date/period filter controls, allows manual category re-assignment and raw SMS viewing, pushes bill due date reminders, features a live home screen widget auto-synced across all transactions, includes an in-house privacy-first promotion engine (static JSON, zero third-party ads), and keeps 100% of user data strictly on the user's device.
